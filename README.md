# SANGA — 地形実験室

水の流れによる侵食・土砂輸送・堆積を3Dで観察する、教育・比較実験用の地形変化シミュレーター。

名前の「SANGA」は、山と川を意味する「山河」に由来する。

TypeScript / React / Vite / Babylon.js / WebGPU / WGSL を使用。

## 主な機能

- 扇状地・河岸段丘・閉じた盆地の地形プリセット
- 降雨、上流流入、土砂供給、浸透、下流端水位の設定
- 侵食・堆積、水深、流速、土壌水分の可視化
- 横断面、地形変化の履歴、水・土砂の収支表示
- 停止中の地形編集とUndo
- 実験のJSON保存・読み込み、PNG出力

計算領域は2.4 km四方、格子解像度は128² / 256² / 512²。

## 動作環境

- Node.js 22.12以上
- pnpm 11（バージョンは `package.json` の `packageManager` で指定）
- WebGPU対応のブラウザとGPU

WebGPUを使用するため、localhostまたはHTTPSで開く必要がある。

## 起動

```sh
pnpm install
pnpm dev
```

表示されたローカルURLを開く。

ドラッグで回転、ホイールで拡大縮小、右ドラッグで平行移動できる。地形の編集は停止中に行う。プリセットや解像度を変更すると実験は初期化される。

河岸段丘の実験では、堆積期に谷底を埋めてから下刻期に切り替える。

## 開発

```sh
pnpm format   # oxfmtで整形
pnpm lint     # oxlintで静的解析
pnpm test     # 自動テスト
pnpm build    # 型検査・本番ビルド
pnpm preview  # ビルド結果のプレビュー
pnpm check    # 整形確認・静的解析・テスト・ビルド
```

依存パッケージは `minimumReleaseAge: 10080` により公開から1週間経過した版を使用する。CIでの導入は `pnpm install --frozen-lockfile` を使う。

関数・メソッドの定義前後は空行で区切る。

実GPUでの検証は、開発サーバーの `/tests/gpu.html` から実行できる。水・固体の保存、非負性、保存・復元の再現性、地形と流れの連成を確認する。

## モデルの制限

平面格子上の高さを扱う2.5Dモデルで、基盤岩と可動土砂を分離し、簡易な流水・土砂輸送・斜面緩和を計算する。土砂は一種類の非粘着性材料を扱う。

浅水方程式の慣性項、複数粒径、粘着性土、地下水圧に基づく斜面崩壊、土石流は扱わない。格子方向への依存性があり、時間刻み・解像度の収束や実地形との較正は未検証。

定性的な教育・比較実験を目的としており、災害や実際の地形変化の定量予測には使用できない。
